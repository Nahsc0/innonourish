# InnoNourish

InnoNourish is an InnoHealth Technologies demonstration of nutrition programme coordination in Kaduna State. Use it to review fictional aggregate reports, track sample actions, edit a budget scenario, and browse official funding information.

The demo uses fictional data and stores edits in the current browser. The institutions shown illustrate possible coordination roles. Use synthetic aggregate data for imports.

## Run locally

Run `npm start` with Node.js 20 or later. Run `npm test` for the core checks and `npm run build` to generate the GitHub Pages site in `dist/`.
